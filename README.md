## 🔧 Projects by domain

### 🖥️ Endpoint Security

`C#` `.NET` `ETW` `FastAPI` `React` `YARA`

### 🧪 Detection Engineering
**[Detection-as-Code](https://github.com/Ayyadi266/Detection-as-code)** — Sigma rules validated with a tiered-evidence model; nothing claimed without a passing test. Mapped to MITRE ATT&CK.
`Python` `Sigma` `MITRE ATT&CK` `CI/CD`

**[Log & Threat Detection Engine](https://github.com/Ayyadi266/log-threat-detection-engine)** — Normalizes Linux/Windows/CloudTrail logs, runs 6 detections + correlation, scores risk, reports HTML/JSON. **247 tests.**
`Python` `MITRE ATT&CK`

### 🌐 Threat Intelligence
**[Threat Intel Platform](https://github.com/Ayyadi266/threat-intel-platform)** — Aggregates free IOC feeds, dedupes across sources, scores confidence with time decay, exports Sigma/STIX. **555 tests, 0 runtime deps.**
`Python` `STIX 2.1` `Sigma`

### ☁️ Cloud SIEM & Automation
**[Sentinel Cloud SIEM](https://github.com/Ayyadi266/sentinel-cloud-siem)** — 9 KQL detections, SOC workbook, Logic App playbook, Bicep IaC — built on the free tier.
`KQL` `Azure` `Bicep`

**[SOAR Playbook](https://github.com/Ayyadi266/soar-playbook)** — Auditable enrichment & triage automation; fail-safe by design, MTTR measured not estimated. **478 tests.**
`Python` `Threat Intel APIs`

### 🏠 Purple Team Lab
**[SOC/SIEM Detection Lab](https://github.com/Ayyadi266/soc-siem-detection-lab)** — Wazuh + Sysmon home-lab framework: 17 ATT&CK-mapped rules with attack-simulation triggers and a full evidence/validation model.
`Wazuh` `Sysmon` `Atomic Red Team`

### 🔐 Application Security
**[Bousana Cars — Secure Platform](https://github.com/Ayyadi266/bousana-cars-secure-platform)** — Secure-by-design car rental platform: Argon2id + pepper, JWT rotation with reuse detection, immutable hash-chain audit log, AES-256-GCM KYC, anti-BOLA. **207 tests.**
`TypeScript` `NestJS` `Next.js` `PostgreSQL` `OWASP`
